最近三年 NBA 新闻采集

范围：2023-11-17 至 2026-11-17，包含首尾日期。固定来源为 Guardian Open Platform，查询 NBA 标签，按月、按页批量获取。这里只表示该来源命中的新闻，不表示全网新闻或完整伤病档案。

怎么开始

  1. 在 官方页面申请 Developer key。当前非商业开发额度每天 500 次、每秒 1 次。实际用途以申请的授权为准。
  2. 在本项目 PowerShell 中设置环境变量，再运行下方命令。key 不要写入代码或发到聊天。
  3. 程序按月分页、去重、保存进度。同一命令再次执行会跳过已保存的页面；失败或达到本次请求预算时保留进度。
$env:GUARDIAN_API_KEY = Read-Host 'Guardian API key'
python scripts/collect_guardian_to_mongodb.py --backfill --start 2023-11-17 --end 2026-11-17

默认每次最多 100 个请求、间隔至少 1.1 秒。额度是账号共享的；预算用尽后检查当天剩余额度再继续。加 --include-body 可请求正文，使用独立输出目录。加 --plan 可离线查看查询范围。

会得到什么

data/collected/guardian_2023-11-17_2026-11-17_metadata/ 中的 news.csv 和 news.jsonl 保存来源 ID、链接、标题、发布时间、获取时间与主题标签；coverage.json 记录每月总数、已取页数、错误和缺口。正文模式另有 _body 目录。

先留来源 ID，之后再建立球队、球员、比赛映射。新新闻没有匹配的历史比赛时保留空值。新闻提及伤病不等于官方伤病状态，官方报告单独采集。

实现与验证

目标：一个无需第三方 Python 包的可恢复采集脚本。依据：用户要求固定来源、最近三年、批量采集。

  1. 在 tests/test_guardian_news.py 先验证月份边界、分页恢复、重复记录、接口失败和缺失时间。
  2. 实现 scripts/collect_guardian_to_mongodb.py --backfill 的日期参数、分页缓存和覆盖率输出。
  3. 运行离线测试及真实连接预检，区分工具验证与实际数据采集。

约束：不修改现有 AGENTS.md、RDS 或原始 NBA 数据；不使用测试 key 批量下载；不把修改时间当成发布时间。失败页面不缓存为成功；范围外或无时间记录单独统计。月份内记录数变化会标记为待复查。
