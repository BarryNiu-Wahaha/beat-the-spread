Code and data access

Get the code from the GitHub repository. Raw data, collected responses, credentials and the local release package are excluded from GitHub. Request data privately from the project owner and preserve the paths shown in the catalog. No S3 upload is required for this checkout.

Scripts read environment variables or hidden prompts; .env.example is reference-only. Run Python in your local environment.

This is a source-and-data handoff, not a deployed application. Local files were inspected; no API collection, RDS migration or cloud upload was performed for this handoff.
